## 6GR 信道编码与调制（11 条）

- **agreement** 10.3.1 — BG3 的子矩阵 E 支持选项 E2：下三角矩阵中，度数大于 1 的列数少于 I。I 的取值仍为 FFS，且 E 不能是单位矩阵（选项 E1）。
- **agreement** 10.3.1 — 除 UE 在其支持的任何频段中最大 UL channel bandwidth 不超过 20MHz 外，支持 BG3 in UL 对 UE 为强制要求，并需进行 capability signaling。对上述 UE，BG3 in UL 为可选；是否需要其他例外由 RAN plenary 决定。
- **agreement** 10.3.1 — 针对 payload size 为 3~11 bits 的 small UCI 编码候选评估，采用 AWGN channel，并报告目标 BLER 下的 SNR、BER，以及收发机复杂度和时延影响。候选包括 5G RM code、Enhanced RM code、Enhanced PC-Polar code、Golay-based code、Vertical and horizontal code、CRC polynomial code；公司可选择一个或多个候选并与 5G RM code 比较。
- **observation** 10.3.1 — 公司贡献指出，5G RM code 在高码率下可能出现 rank deficiency、error floor 或性能下降；同时有意见认为 small UCI 通常采用低码率，且 5G RM code 可复用。贡献还提出 Enhanced RM code、Enhanced PC-Polar code、Vertical and horizontal code、CRC polynomial code、Golay-based code 等提升候选。
- **conclusion** 10.3.2 — RAN1 将继续研究 GS（1D-NUC）及 PS（ESS-based PS、ECC-based PS），并在 Q3 决定是否支持 constellation shaping；如支持，将在 PS（含 1-bit 或 2-bits）与 GS 之间选择。DL 与 UL 不支持采用不同的 constellation shaping scheme；若 Q3/26 未达成共识，相关研究将停止。
- **conclusion** 10.3.2 — 该条目指出 RANP 要求 RAN1 就 constellation shaping 的支持作出结论，未包含进一步的结论内容。
- **conclusion** 10.3.2 — RAN1 对 DL 或 UL 支持任何 constellation shaping scheme 均未达成共识。部分方案的支持者表示愿意撤回相应方案。
- **conclusion** 10.3.2 — 若在 6GR 中支持 DL 4K QAM 和 UL 1K QAM，其适用范围限于 FWA use case，不适用于 eMBB，且该限制须在规范中落实。RAN1 建议采用 UL 1K QAM；对 DL 4K QAM 是否采用未达成共识。
- **observation** 10.3.2 — 原文仅引出相对于 RAN#112 结论的观察，未提供具体观察或决定。
- **observation** 10.3.2 — 提供了 UL 1K QAM 的 SLS 评估结果，其中部分结果符合 RAN4 推荐的 EVM/MPR，部分不符合。结果显示不同场景和配置下的 UPT 增益不一；多项评估指出，在户外 CPE 等情形可见增益，而 MPR、EVM、负载及 rank 会影响收益。
- **observation** 10.3.2 — 提供了 DL 4K QAM 的 SLS 评估结果，分别报告符合和不符合 RAN4 推荐 EVM 的评估。结果显示增益依场景、负载、rank 和 impairment model 而异；多项评估报告平均增益很小或为负，也有评估在 FWA 户外 CPE 或特定条件下报告正增益。

## 6GR 能效（10 条）

- **agreement** 10.4.1 — 进一步研究 idle mode 多载波初始接入时，至少考虑 UL 覆盖增强或 DL-UL 覆盖不平衡、RACH 容量/卸载/负载均衡、网络节能/减少公共信令等用例。对每个用例研究多载波操作相对现有机制在何种条件下能带来额外收益；不排除其他用例。
- **agreement** 10.4.1 — 研究 idle mode 多载波初始接入时，考虑三类候选物理载波场景：1 DL + 多个 UL、多个 DL + 1 UL、多个 DL + 多个 UL。UE 对给定初始接入过程可只使用候选载波的子集；纳入研究不代表同意支持，需求及适用用例和部署场景仍待进一步研究。
- **agreement** 10.4.1 — 对所述 idle mode 多载波初始接入研究，基线规定：一次 RACH procedure 尝试中，每个链路方向使用一个选定的 physical carrier。
- **agreement** 10.4.1 — 进一步研究 idle mode 多载波初始接入时，至少考虑三类部署条件：可假设共同 timing/frequency synchronization relationship 的共址载波、不能假设该关系的共址载波，以及不能假设该关系的非共址载波。其他相关部署假设按适用情况考虑，包括载波频率关系/频带间隔、numerology/duplexing configuration 和 UE RF/baseband capability；同步关系是否可假设以 UE 视角判断。
- **agreement** 10.4.2 — 研究 6GR 中跨载波 UL transmission switching，至少考虑所有 UL signals/channels 是否及如何采用统一设计、切换信令方式、Tx chains 和 carriers 数量、switching gap，以及与 carrier aggregation 的交互。按需与其他工作组（例如 RAN4）协调；SRS antenna switching 在 UL CSI 议程另行讨论。
- **agreement** 10.4.2 — 研究 6GR 中跨载波 DL reception switching，至少识别适用场景，包括 NR LB-CA 所考虑的场景，并按需与其他工作组（例如 RAN4）协调。
- **agreement** 10.4.2 — 研究 6GR connected mode 多载波操作中快速启用/禁用访问 additional carriers 的机制，至少考虑 UE power saving 和/或 NW energy saving、carrier states、启用/禁用方式，以及假设的 NW-side 和 UE-side 要求。
- **agreement** 10.4.2 — 研究 6GR connected mode 多载波操作中的 PXSCH 资源分配机制，考虑 PXSCH 限于单个 carrier 或跨多个 carriers。还需考虑适用场景和条件，以及按需与其他 WG（如 RAN4）协调。
- **agreement** 10.4.2 — 研究 6GR connected mode 多载波操作中的 PXSCH 调度机制，涵盖 self-carrier、cross-carrier 和 multi-carrier scheduling，并考虑各机制的适用场景和条件及按需与其他 WG（如 RAN4）协调。Multiple slot scheduling 将在其他议程单独讨论。
- **agreement** 10.4.2 — 对于 6G UE 在 CONNECTED mode 下的 single carrier bandwidth operation，6GR-BW 至少应包含 carrier 内的频率位置和连续 PRB 数量；研究是否还需关联其他参数，并尽量减少相关参数数量。还需研究与 6GR-BW 相关的信号/信道收发，以及 DL 和/或 UL 切换的收益、必要性和潜在机制。
