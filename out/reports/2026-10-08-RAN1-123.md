## 6GR 信道编码与调制（10 条）

- **agreement** channel-coding-0cf828bf — 对于载荷大于 NR 范围（即超过 1706 bits）的 UCI Polar code 设计，至少将 more than 2 segments 作为进一步研究选项。是否需要超出 NR 范围的 UCI 载荷，需由其他议题确认。
- **agreement** channel-coding-0cf828bf — 针对超出 NR 范围数据速率的 LDPC 扩展研究，需在 RAN1#124 前提供初版 LDPC BG(s) 和 PCM(s)，并给出目标 BLER 所需 SNR、复杂度及译码算法评估假设。复杂度定义将进一步讨论，其他指标仍为 FFS。
- **agreement** channel-coding-0cf828bf — 针对 3~11 bits 小载荷 UCI 的信道编码研究，至少考虑 5G RM code。若 5G RM code 存在可论证的缺点，应识别并研究潜在解决方案。
- **agreement** channel-coding-0cf828bf — LDPC 扩展的 BG(s) 和 PCM(s) 评估将考虑给定的 AWGN 信道、调制与码率、交织器、码块大小、目标 BLER 及译码算法假设，这些假设仅用于仿真，不影响最终设计。候选方案需同时比较性能和复杂度，且 BLER 性能比较须在相同计算复杂度下进行，计算复杂度按所需 BLER 的迭代次数与提升后校验矩阵中 1 的数量之积除以 CB size 定义。
- **conclusion** channel-coding-0cf828bf — 对于载荷处于 NR 范围内且大于 11 bits 的 Polar code 设计潜在扩展或增强，其动机尚无共识。
- **agreement** modulation-joint-channel-coding-and-modu-ff7518f4 — 对 PS/GS 固定 MCS 的性能报告，采用以 10% BLER 为目标的表格格式作为仿真结果报告起点；NR 参考需提供 modulation order 与 coding rate，而不只提供 MCS index。表格包含各 SE 点参数、均匀 QAM 基线 SNR、相对 NR baseline 的增益或损失及方案假设；其他指标（至少 complexity）可在细节达成一致后并入。
- **agreement** modulation-joint-channel-coding-and-modu-ff7518f4 — 为比较 PS/GS 与 uniform QAM，规定复杂度、存储、处理时延及并行性/串行性的报告项目；复杂度按 information bits 归一化，并以比较、加减、乘除运算数表示。复杂度和存储按其是否依赖 SE 点分别加入既有性能报告表的列或行，规范影响另行评估。
- **agreement** modulation-joint-channel-coding-and-modu-ff7518f4 — 对 PS/GS 固定 MCS 的性能报告，采用以 10% BLER 为目标的表格格式作为仿真结果报告起点；NR 参考需提供 modulation order 与 coding rate，而不只提供 MCS index。表格包含各 SE 点参数、均匀 QAM 基线 SNR、相对 NR baseline 的增益或损失及方案假设；其他指标（至少 complexity）可在细节达成一致后并入。
- **agreement** modulation-joint-channel-coding-and-modu-ff7518f4 — 研究允许一个 spectrum efficiency point 对应多个 MCS entries 的方案，并要求报告 MCS table 设计与预期大小、不同映射方式下的性能，以及不同信道和 rank 假设下的收益。性能基线包括最高至 256 QAM 的 legacy MCS table；另需说明同一 SE 对应多个 MCS 时的选择机制及可能需要的 UE feedback。
- **agreement** modulation-joint-channel-coding-and-modu-ff7518f4 — 针对 DFT-s-OFDM，进一步研究 PS/GS 是否以及如何能够相较 uniform QAM 实现 Net Gain。

## 6GR 波形与帧结构（12 条）

- **agreement** frame-structure-ecea07cd — RAN1 假设 FR2-1 网络侧最大信道带宽为 800MHz 或 400MHz，具体值将在未来择一确定。UE 侧是否采用 800MHz 或 400MHz 仍为 FFS。
- **agreement** frame-structure-ecea07cd — 研究网络支持 400 MHz CBW 时使 UE 支持 400 MHz 带宽的选项，包括假设 single FFT 和 2 RF chain 的 Option 5。还需研究 BB processor 的分离或并行方式、各选项的规范影响及性能、能效、成本和复杂度，并将信息告知 RAN4。
- **agreement** frame-structure-ecea07cd — Draft LS R1-2509577 原则上获认可，最终 LS R1-2509578 获批准。
- **conclusion** frame-structure-ecea07cd — TN communication 的 Extended CP 不再继续研究。
- **agreement** waveform-6eae1e79 — 在 RAN1#122b 已有协议基础上，为 UL PAPR reduction 增加评估指标：在 spectral efficiency 相近且 occupied bandwidth 相同条件下的 Net gain@10% BLER，以及 ACLR、EVM 和 IBE。
- **agreement** waveform-6eae1e79 — 为 UL low-PAPR proposals 设定通用评估假设，包括 4GHz 载频、Urban 场景至少 100MHz Channel BW、30 kHz SCS 和 TDL-C 300ns 信道模型。还规定 UE speed 为 3km/h、TDL 信道下 1 个 Tx 天线和 1 或 4 个 Rx 天线、每 slot 2 个 DMRS 与 12 个 PUSCH 数据符号，并采用无重传 HARQ、禁用 frequency hopping。
- **agreement** waveform-6eae1e79 — 规定 UL low-PAPR proposals 在 single user 评估中，针对 spectrum extension 和 spectrum truncation 分别使用 MCS 与子载波数量报告假设，并列出扩展或截断前后的子载波数及 occupied bandwidth。其他 extension 或 truncation 数值不受排除。
- **agreement** waveform-6eae1e79 — 对 CP-OFDM 和 DFT-S-OFDM 的 tone reservation UL low-PAPR proposals，规定 single user 评估需报告 MCS、occupied bandwidth 中的子载波数、保留 tone 数量（inband/sideband）及保留比例。
- **agreement** waveform-6eae1e79 — 通过用表格表征各 waveform proposal，作为潜在的 RAN1 observation。表格涵盖提案动机、适用链路方向、波形增强、目标信道或信号、KPI、规范影响及兼容性等项目。
- **agreement** waveform-6eae1e79 — UL PAPR reduction 评估采用 occupied BW B 对应的 PRB 数值：2、4、8、16、24、30、32、64、128、240、256；其他 PRB allocation 也允许考虑。还应考虑 TS 38.101 定义的 edge、outer 和 inner PRB allocations。
- **agreement** waveform-6eae1e79 — Performance benefit 需通过 link level 和 system level simulation 评估，metrics 仍待确定。条目给出了 multi-layer UL waveform link level study 的参数，包括 4 GHz、30 kHz、CP-OFDM/DFT-s-OFDM、2 或 4 layers、10% BLER target 等。
- **agreement** waveform-6eae1e79 — 规定了 multi-layer UL CP-OFDM/DFT-s-OFDM system level study 的配置，包括 UMa 21 cells、每小区 10/30/50 UEs、至少 100 MHz 带宽和 30 kHz 子载波间隔等。UL low-PAPR proposals 的 link level multi-user evaluation 假设为 2 users，并列出 RB overlap、baseline scheme、MCS 对齐方式及由提案方报告 receiver 类型。
