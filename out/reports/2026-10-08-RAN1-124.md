## 6GR 信道编码与调制（13 条）

- **agreement** 10.3.1 — 针对超出 NR 范围的 LDPC extension，RAN1#124 确定 maximum code block size 的两个进一步研究选项：8448 和 8448*2。
- **agreement** 10.3.1 — 针对超出 NR 范围的 LDPC extension，RAN1#124 确定 BG 中 information columns 数量的三个进一步研究选项：22、44 和 33。
- **agreement** 10.3.1 — 针对 LDPC extension beyond NR range，确定进一步研究 rate matching 前 puncturing 的三种选项：不 puncture、puncture 1 column、puncture 2 columns。
- **agreement** 10.3.1 — 为评估 payload size 超过 NR 范围且大于 1706 bits 的 L1 uplink control information 的 Polar code segmentation enhancement，列出了评估假设，包括 AWGN、QPSK、多个 code rate、CRC-aided SCL decoding 和 BLER 目标。每段使用 11 bits CRC，rate matching、channel interleaver 和 code-block concatenation 沿用 NR；其他评估取值由公司报告。
- **agreement** 10.3.1 — LDPC extension beyond NR range 的 maximum lifting size 不大于 384；其确切取值仍待研究。
- **agreement** 10.3.1 — LDPC extension beyond NR range 进一步研究采用 quasi-cyclic LDPC codes，其 parity check matrix 由 circularly shifted matrices 或 zero matrices 组成，且循环移位矩阵的 row weight 不超过 2。mb、nb、z 的取值以及循环移位矩阵的 row weight 配置仍待研究。
- **agreement** 10.3.1 — LDPC extension beyond NR range 的 BG1 与公司提出的 BG(s)/PCM(s) 性能比较，至少考虑在相同 BLER 下的 computational complexity 差异，以及相同计算复杂度下的 SNR 性能差异。BG1 的 reference maximum number of iterations 为 5、7、10、15，公司也可报告其他值及平均迭代次数差异。
- **agreement** 10.3.2 — 列出了影响 PS 与 GS 复杂度、存储、时延、BLER 和 throughput 权衡的参数，并要求提交评估所用参数及性能结果。鼓励公司评估不同参数组合，以研究不同权衡并提供可行性评估。
- **agreement** 10.3.2 — DL 4K uniform QAM 和 UL 1K uniform QAM 的研究聚焦 FWA 室外及室内部署场景，in-door hot-spot 仍待研究。相关 CPE SLS 假设采用 Dense Urban 和 UMA layout，其他 SLS 参数仍待研究。
- **agreement** 10.3.2 — 决定向 RAN4 发 LS，请其提供不带 shaping 的 DL 4K uniform QAM 和 UL 1K uniform QAM 的 EVM 与 MPR 数值。
- **agreement** 10.3.2 — 针对 PS，列出了 TX/RX chain functionality blocks 的潜在影响，包括新增 DM 功能，以及 TBS calculation、CB segmentation、interleaving、scrambling 和 modulation 等功能的修改；RX 侧还涉及 DDM、demodulation 和 CB concatenation。鼓励公司提供相关功能修改的设计细节，并说明未受影响功能块的原因。
- **agreement** 10.3.2 — R1-2601663 中的 draft LS 获得认可，最终 LS 在 R1-2601664 中获批。
- **agreement** 10.3.2 — 已识别 GS 相比 NR 对 TX/RX chain 功能块的潜在影响，包括映射、调制符号生成、接收符号解调和解映射。鼓励公司在同时支持 NUC 和 uniform QAM 时说明影响、所需设计修改及未受影响功能块的原因。

## 6GR 能效（16 条）

- **agreement** 10.4 — 为 NES 评估和候选 6GR 节能方案的相对比较，定义基线网络配置：单小区至少采用 20 ms 周期的 SSB，并规定 SIB1、RO 的可选周期配置。公司需报告相关 BS 处理值和平均网络负载，也可在说明理由后评估其他配置；该评估不用于与 5G/NR 比较能效。
- **agreement** 10.4 — 已采纳 BS reference configuration Set 4 中 CAT1 和 CAT2（若支持）的转换时间：Deep sleep 分别为 50 ms 和 10 s，Light sleep 分别为 6 ms 和 640 ms。是否因 TXRU 数量较多而需要 delta value 仍待讨论。
- **agreement** 10.4 — 已采纳 BS reference configuration Set 4 中 CAT1 和 CAT2（若支持）的相对转换能量：Deep sleep 分别为 1075 和 31500，Light sleep 分别为 163 和 1344。是否因 TXRU 数量较多而需要 delta value 仍待讨论。
- **agreement** 10.4 — 若引入 BS model CAT 2.1 (2-plus)，其 Set 1–3 转换特性包括 Deep Sleep 转换时间 2 s、Light Sleep 转换时间 100 ms，以及对应额外转换能量 3400 和 170。Set 4 仍待讨论。
- **agreement** 10.4 — 将 UL long PUCCH/PUSCH/PRACH 的 TX power 与 relative power 值纳入 UE power model，UE reference configuration 为 1TX chain。0 dBm 对应 250、23 dBm 对应 700（均为 agreed; reference only），并列出 10、15、20、26 dBm 对应值。
- **agreement** 10.4 — 已采纳 6GR UE power consumption model 的 cross-slot scheduling scaling：PDCCH-only 的 cross-slot scheduling 功耗为 same-slot scheduling 的 0.7 倍。该规则适用于 FR1（包括约 7GHz）和 FR2（包括 24.25–52.6 GHz）。
- **agreement** 10.4 — 将 DL antenna scaling factors 纳入 6GR UE power consumption model，适用于 FR1 和 FR2；FR2 假设 DL antenna 数量最多为 4。已给出 6Rx、4Rx、2Rx、1Rx 相对于 4Rx 或 2Rx 的 scaling，8Rx scaling 仍待讨论。
- **agreement** 10.4 — RAN1 将进一步定义带宽为 20MHz 或更小的 UE reference configuration。是否对两种 reference configuration 应用不含 SMaxBW 的相同 scaling rules，以及是否复用或扩展 NR TR 38.875 的 reference configuration 和 power values，仍待讨论。
- **agreement** 10.4 — 更新 6GR UE power model 中 PDCCH+PDSCH bandwidth scaling table，列出不同 ΓB 和 ΓTput 下的 scaling values，并规定 adaptation delay = Tmin 不大于 NR BWP switch delay (Type 2)。SMaxBW 取值方案及允许 adaptation delay 时 scaling factor 的选项需由公司报告评估假设。
- **agreement** 10.4 — 更新 6GR UE power model 中 PDCCH-only bandwidth scaling table：在 adaptation delay = Tmin（不超过 NR BWP switch delay (Type 2)）时，表格按 ΓB、ΓTput 和 SMaxBW 给出 scaling values，并要求公司报告评估采用的 SMaxBW 选项。若允许 adaptation delay，scaling factor 可选 0.8 或 0.6，评估所用选项也需报告。
- **agreement** 10.4 — 在 6GR UE power model 中加入 micro sleep 的 bandwidth scaling table；在 adaptation delay = Tmin（不超过 NR BWP switch delay (Type 2)）时，按 ΓB 设置 scaling factor，并要求公司报告采用的 SMaxBW 选项。还规定了按 DL antenna number 的 scaling factor；是否将这些 scaling rules 应用于 light sleep 仍待研究。
- **agreement** 10.4 — FR1 的 EE Processing 2-RX 采用表中 Micro sleep、Light sleep 和 Deep/Ultra-deep 的数值；1-RX 数值作为已同意的参考值。若 EE processing reception time 为一个 slot 内的 X 个 symbols，power value 按 X/14 缩放；additional energy overhead 是否缩放及 10MHz BW 的数值仍待研究。
- **agreement** 10.4 — 引入 BS model CAT 2.1。CAT 1、CAT 2 和 CAT 2.1 均可用于 6GR SI evaluations。
- **agreement** 10.4 — EE evaluations 中，需研究将 BS active antenna TXRU 数量调整为总数的 1/2 和 1/4，并调整相关 circuitry。BS power model、power states、state transitions、覆盖与吞吐等事项仍列为待研究内容。
- **agreement** 10.4 — 基于 one RF chain 的 CA reception，其 power scaling factor 与相同 total bandwidth 的 bandwidth scaling 相同；该缩放假设所有 CCs 均已激活，且不影响 carrier activation/deactivation delay。PDCCH-only slots 的单独缩放，以及基于多个 RF receive chains 的 CA reception 缩放仍待研究。
- **agreement** 10.4 — 6GR UE power consumption model 采用 UL scaling：假设 Short PUCCH 和 SRS 均为 1-symbol 时，其功率分别为 uplink power 的 0.3 倍。该规则适用于 FR1（包括 around 7GHz）和 FR2（包括 24.25 GHz–52.6 GHz）；不同 symbol numbers 的 scaling 仍待研究。

- **agreement** 10.1 — 针对 Massive Communication (IoT) 的 6GR 评估，除 IMT-2030 L2 PDU 的 32 bytes 消息大小外，也可评估更高业务负载，例如采用 320 bytes 的较大 L2 PDU 消息大小。

## 6GR 多天线系统（61 条）

- **agreement** 10.5.0 — 对于至少一种 lower-tier device 的 6GR 最小 maximum UE bandwidth，RAN1 将进一步研究三种备选方案：包括不同的 FDD/TDD RF 和 BB bandwidth、SCS 配置，以及更窄的 UL 和/或 DL BB bandwidth。
- **agreement** 10.5.0 — 针对复用 5G mid-band（~3.5 GHz）site grid 在 around 7 GHz 部署并达到可比覆盖的研究，需进行 link budget evaluation 以识别 around 7 GHz 的 coverage gap。初始接入采用 Rel-15 NR signals/channels，将各 signal/channel 与 5G mid-band 的 Rel-15 NR msg3 分别比较；候选 coverage enhancement techniques 将另行讨论。
- **agreement** 10.5.0 — 针对 6GR spectrum aggregation operation，研究两种方法及其适用场景：将多个 physical carriers 聚合到单个 “Gothia cell”，或采用 carrier aggregation 将其聚合到 separate cells。“Gothia cell”仅用于 RAN1 讨论；两种方法均需在 idle mode 和 connected mode 下研究，并评估网络侧和 UE 侧的优缺点。
- **agreement** 10.5.0 — 为5G mid-band Msg3 PUSCH的link budget template candidate 1列出了假设参数，包括TBS 56 bits、10% BLER target、90% cell area reliability，以及发射和接收端配置。部分参数仍为FFS或由公司报告/计算，最大覆盖距离也标为FFS。
- **agreement** 10.5.0 — 为约7 GHz信号/信道的link budget template candidate 1列出了初始接入（假设Rel-15 NR design）的评估参数，包括SSB数量、基站和UE天线配置、发射功率及接收噪声系数。部分参数仍为FFS或由公司报告/计算，并要求公司在4月3日前提供更新后的link budget结果。
- **agreement** 10.5.0 — 6GR至少应能够配置与5G NR中已部署的相同TDD slot configurations。
- **agreement** 10.5.0 — 研究dynamic TDD的link direction determination，并至少考虑UE PDCCH monitoring effort与功耗、signaling overhead、scheduling flexibility、避免功能重复及collision handling。
- **agreement** 10.5.1.1 — 针对6GR初始接入和移动性，研究部署场景，包括单波束与多波束、单TRP与多TRP、单载波与多载波部署，以及其他部署场景。
- **agreement** 10.5.1.1 — 针对6GR paging transmission/reception，研究促进网络节能和UE节能的paging方案，并研究是否需要增强paging capacity或coverage。
- **agreement** 10.5.1.1 — 研究用于6GR初始接入和idle mobility的信号、信道与流程，至少涵盖小区搜索与cell ID识别、时频同步/跟踪、波束测量和系统信息获取。还需考虑上述流程中TRP对UE是否透明。
- **agreement** 10.5.1.1 — 针对6GR初始接入和移动性测量，研究measurement resource、measurement quantity、measurement functionality和measurement procedure，至少包括L1 measurements以及小区级/[TRP级]和波束级测量。
- **agreement** 10.5.1.1 — 研究6GR初始接入期间的beam operation，包括波束获取、波束报告/细化，以及空间/时间波束预测的可行性和性能。
- **agreement** 10.5.1.1 — 定义6GR基本同步信号结构为6GR SSB，由primary synchronization signal(s)、secondary synchronization signal(s)和physical broadcast channel(s)组成。其他类型的6GR同步信号/信道结构或参考信号及其结构仍为FFS。
- **agreement** 10.5.1.2 — 研究 random access framework，涵盖能效、覆盖改善、不同设备类型和能力、降低开销及简化信令/配置，并考虑 latency、capacity、detection reliability 和 high speed mobility。研究还考虑 NTN、SBFD、multi-carrier、multi-TRP 等场景，以及是否需要相应的特殊处理或功能。
- **working_assumption** 10.5.1.2 — 采用 random access 评估的 link level simulation assumptions，涵盖载波频率、duplex、带宽、numerology、天线配置、channel estimation、channel model、mobility 和 RF impairments。PRACH 评估参数包括 RO、序列与格式及目标性能；Msg.3 PUSCH 参数包括 frequency hopping、DMRS、HARQ、时长和 PRB 数等。

- **agreement** 10.6.2 — 进一步研究 standalone cell 场景下 UL WUS 的必要性与可行性，包括发送前无信号、仅有常开同步信号（可带 PBCH）但无 SIB1，以及有 PBCH 和周期性 SIB1 三种情形。RAN1 至少考虑 UL WUS 覆盖目标、UE 如何获取同步和决定发射功率，以及适用的 RRC states；这些场景仅用于研究，不表示 6GR 支持。
- **agreement** 10.6.2 — 进一步研究 UE 从 cell/carrier #1 获取 UL WUS 配置的 multi-cell/carrier 场景下，UL WUS 的必要性与可行性；cell/carrier #2 在发送前可无信号、仅有常开同步信号，或有 PBCH 和周期性 SIB1。RAN1 至少考虑覆盖目标、同步获取、发射功率、频段与共址情况、RRC states，以及是否适用于 multi-TRP；这些场景仅用于研究，不表示 6GR 支持。
