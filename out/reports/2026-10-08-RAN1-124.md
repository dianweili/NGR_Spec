# RAN1 #124 增量简报

> 共 174 条事件 · [会议目录](https://www.3gpp.org/ftp/tsg_ran/WG1_RL1/TSGR1_124/)

## 本会议特性进展（6G）

### 6GR 信道编码与调制（基于 13 条已摘要 6G 事件）

RAN1#124 明确了 6GR 超出 NR 范围的 LDPC extension 的候选参数、结构研究约束与性能比较要求，并建立了大 payload L1 uplink control information 的 Polar code segmentation enhancement 评估假设。调制方面，会议推进了 PS/GS 的性能权衡与 TX/RX chain 潜在影响研究，明确高阶 uniform QAM 的重点研究场景，并批准向 RAN4 征询 EVM 与 MPR 数值的 LS。这些进展为编码及调制方案的后续比较提供了评估基础，尚未形成最终方案选择。

**关键结论**

- LDPC extension 的进一步研究选项包括：maximum code block size 为 8448 或 8448*2；BG information columns 数量为 22、44 或 33；rate matching 前不 puncture、puncture 1 column 或 puncture 2 columns。
- LDPC extension 的 maximum lifting size 不大于 384；进一步研究 quasi-cyclic LDPC codes，其 parity check matrix 由 circularly shifted matrices 或 zero matrices 组成，循环移位矩阵的 row weight 不超过 2。
- BG1 与公司提出的 BG(s)/PCM(s) 至少比较相同 BLER 下的 computational complexity，以及相同计算复杂度下的 SNR 性能；BG1 reference maximum number of iterations 为 5、7、10、15。
- 针对超过 NR 范围且大于 1706 bits 的 L1 uplink control information，Polar code segmentation enhancement 评估采用每段 11 bits CRC，rate matching、channel interleaver 和 code-block concatenation 沿用 NR，并列出了 AWGN、QPSK、code rate、CRC-aided SCL decoding 和 BLER 目标等评估假设。
- PS/GS 评估须报告所用参数及性能结果，以比较复杂度、存储、时延、BLER 和 throughput；会议识别了 PS 与 GS 对 TX/RX chain 功能块的潜在影响，并鼓励提交设计修改细节。
- DL 4K uniform QAM 和 UL 1K uniform QAM 研究聚焦 FWA 室外及室内部署，CPE SLS 采用 Dense Urban 和 UMA layout；向 RAN4 征询不带 shaping 的 EVM 与 MPR 数值的最终 LS 已在 R1-2601664 中获批。

**待决问题**

- LDPC extension 的 maximum code block size、information columns 数量及 puncturing 方案仍需从候选选项中进一步研究；maximum lifting size 的确切取值、mb、nb、z 及循环移位矩阵 row weight 配置尚待确定。
- Polar code segmentation enhancement 的其他评估取值需由公司报告。
- PS/GS 不同参数组合的性能权衡与可行性仍需评估，相关 TX/RX chain 功能修改细节及未受影响功能块的原因仍需补充；GS 还需说明同时支持 NUC 和 uniform QAM 时的影响。
- 高阶 uniform QAM 的 in-door hot-spot 场景及其他 SLS 参数仍待研究。
- 不带 shaping 的 DL 4K uniform QAM 和 UL 1K uniform QAM 的 EVM 与 MPR 数值待 RAN4 提供。

### 6GR 能效（基于 16 条已摘要 6G 事件）

RAN1#124 明确了用于 NES 评估及候选 6GR 节能方案相对比较的基线网络配置，并完善了 BS 与 UE 功耗模型。会议采纳了 BS Set 4 的转换参数、引入 CAT 2.1，并推进 UE 调度、带宽、天线、CA reception 和 UL 功耗缩放规则。这些结论为 6GR SI 能效评估提供了共同建模依据及评估假设报告要求；该基线评估不用于与 5G/NR 比较能效。

**关键结论**

- NES 基线网络配置规定单小区 SSB 周期至少为 20 ms，并给出 SIB1、RO 可选周期；公司需报告相关 BS 处理值和平均网络负载，其他配置需说明理由。
- BS reference configuration Set 4 采纳 CAT1/CAT2（若支持）的 Deep sleep 转换时间 50 ms/10 s、相对转换能量 1075/31500，以及 Light sleep 转换时间 6 ms/640 ms、相对转换能量 163/1344。CAT 2.1 已引入，与 CAT 1、CAT 2 均可用于 6GR SI evaluations。
- UE model 纳入 1TX chain 下 UL long PUCCH/PUSCH/PRACH 的 TX power 与 relative power；0 dBm 对应 250、23 dBm 对应 700 为已同意的参考值。1-symbol Short PUCCH 和 SRS 功率均按 uplink power 的 0.3 倍计。
- PDCCH-only 的 cross-slot scheduling 功耗采用 same-slot scheduling 的 0.7 倍，适用于 FR1 和 FR2；DL antenna scaling 纳入 6Rx、4Rx、2Rx、1Rx，FR2 假设 DL antenna 数量最多为 4。
- 更新 PDCCH+PDSCH、PDCCH-only 和 micro sleep 的 bandwidth scaling，并规定 adaptation delay = Tmin 不超过 NR BWP switch delay (Type 2)，相关选项需报告。FR1 EE Processing 采用 2-RX 表值，1-RX 为已同意参考值，接收 X 个 symbols 时 power value 按 X/14 缩放。
- 基于 one RF chain 的 CA reception 采用与相同 total bandwidth 相同的 bandwidth scaling，假设所有 CCs 均已激活，且不影响 carrier activation/deactivation delay。

**待决问题**

- BS Set 4 是否因较多 TXRU 而增加转换参数 delta value，以及 CAT 2.1 的 Set 4 转换特性，仍待讨论。
- 需研究将 BS active antenna TXRU 数量调整为总数的 1/2 和 1/4，并调整相关 circuitry；对应 BS power model、power states、state transitions、覆盖与吞吐仍待研究。
- 需进一步定义带宽为 20 MHz 或更小的 UE reference configuration，并讨论两种 reference configuration 是否采用不含 SMaxBW 的相同 scaling rules，以及是否复用或扩展 NR TR 38.875 的配置和功耗值。
- 8Rx scaling、micro sleep scaling rules 是否适用于 light sleep，以及 EE Processing 的 additional energy overhead 是否缩放和 10 MHz BW 数值，仍待研究。
- Bandwidth scaling 中的 SMaxBW 及允许 adaptation delay 时的 scaling factor 选项仍需公司报告评估假设；PDCCH-only 的相关 scaling factor 可选 0.8 或 0.6。
- CA reception 在 PDCCH-only slots 的单独缩放、多个 RF receive chains 的缩放，以及 Short PUCCH/SRS 不同 symbol numbers 的缩放，仍待研究。

### 6GR 空口评估假设（基于 12 条已摘要 6G 事件）

本会议进一步明确了 6GR 空口评估的天线建模、发射功率、用户分布与速度以及业务模型假设，覆盖低于 30 GHz 和约 30 GHz 的 UE、BS 及 FWA/CPE 配置。这些约定细化了系统级仿真的共同评估基线，同时保留部分可选配置、公司报告参数和评估阶段待定事项；其含义是统一评估条件，尚不构成空口协议机制的确定。

**关键结论**

- 低于 30 GHz 的 UE antenna modelling 覆盖 1、2、4、8、16 个 antenna elements 及对应 TXRU、Alt 1/Alt 2 和适用载频；Alt 1/Alt 2 的天线位置为性能校准示例，也可采用 TR 38.901 section 7.3 的其他阵列结构或位置。
- 约 30 GHz 的 UE antenna configuration 和 radiation pattern 分别遵循 Table 1 和 Table 2；每 panel 含 8 个 antenna elements，Config 0/1/2 分别为 1/2/4 个 panels，并规定每 panel 的 TXRU 配置，GE,max 为 5 dBi。其他配置可考虑并由公司报告。
- FWA/CPE 单天线单元方向图候选包括 Isotropic、Directional 和 Omnidirectional；CPE 可配置 1–3 个 panels 并优化方向。约 4 GHz 的室外 BS 增列 32 个 antenna elements、4 TXRU 的 Optional 配置。
- 系统级仿真中，低于 30 GHz 时仅 CPE 假设 UE transmission power 为 35 dBm，可考虑 EIRP limit；约 30 GHz 的 peak EIRP 范围为 23–43 dBm，仅 CPE 为 35–55 dBm，具体仿真功率由公司报告。BS Tx power 随带宽按比例增加，室外和室内最大功率分别为 56 dBm 和 33 dBm。
- 更新了 Indoor Hotspot、Dense Urban、Rural、Urban Macro 和 Suburban Macro 的 UE 分布与速度假设，每个 micro TRxP 的 UE 数量不大于对应 macro TRxP；采用覆盖 Rural、Urban Macro 和 Suburban Macro 的 CPE antenna height、UE distribution 和 UE speed 假设。TR38.914 已涵盖但 RAN1 尚未讨论的场景也纳入候选评估场景。
- FTP3 extension 设定两种包大小，满足 S₁<S₂、λ₁=K·λ₂、K≥1，到达服从 Poisson distribution，并保留每 UE 一种包大小和每 UE 两种独立 Poisson Process 两种方案。Massive Communication (IoT) 除 32 bytes L2 PDU 外，也可评估如 320 bytes 的更高业务负载。

**待决问题**

- UE 分布和速度表对 FWA 的适用性仍为 FFS。
- 室内与室外 CPE 的预选标准或机制可在评估阶段进一步讨论。
- FTP3 extension 两种方案的相关参数取值留待评估阶段决定。

### ISAC 通感一体（基于 5 条已摘要 6G 事件）

本会议推进了 Rel-20 study 中 Device 2b 与 Device C 的评估材料整理，确定将更新后的 TP 及 coverage 评估结果纳入 TR38.769，并补充各公司的 energy harvesting/storage assumptions。RAN1 明确了两类设备的 coverage 差异及对应户外距离范围，为后续设备必要性和 Device C maximum transmit power 的选择提供依据，但未确定最终功率取值。

**关键结论**

- 采用 R1-2600466 所附 Moderator’s evaluation summary 中更新后的 TP，并纳入 TR38.769。
- 将 Device 2b 和 Device C 的 R2D、D2R coverage 评估 TP 纳入 TR38.769 第 7.3 节，按 cell edge data rate、UMa NLOS pathloss model、penetration margin、Tx power 和 BLER 等条件汇总 achievable maximum distance。
- Device C 的 R2D 和 D2R coverage 均优于 Device 2b；Device 2b 适用于 50–200m 户外场景，Device C 适用于 50–500m 户外场景。
- RAN1 观察到 Device C 在户外实现 maximum coverage 时的 maximum transmit power 为 5 dBm；-3 dBm 至 5 dBm 的不同取值可实现不同 coverage。

**待决问题**

- Device 2b 和 Device C 在 coverage 以外方面的必要性仍由 RAN 决定。
- Device C 的 maximum transmit power 尚未最终选定，RAN 仍可选择 -3 dBm 至 5 dBm 范围内的任一值。

### 6GR 多天线系统（基于 61 条已摘要 6G 事件）

RAN1#124 推进了 6GR 多天线系统的研究范围与评估框架，重点涵盖 beam management、DL/UL CSI acquisition、DMRS 扩展及 tracking RS。本会议采纳了多项链路级和系统级评估假设，并明确 CSI prediction、AI-based CSI compression 等方案的指标与基线，为后续比较性能、反馈开销和复杂度提供依据。协议层面主要明确了待研究的机制和接口要素，具体波束管理流程、DMRS 端口规模及联合 CSI acquisition 设计尚未定案。

**关键结论**

- DL-based CSI acquisition 已采用 SLS 和 LLS 基本假设；系统级基线指标包括 throughput 和 CSI feedback overhead，性能基线包括 Rel-19 Type I Scheme A/B、Rel-19 eType II Codebook 及用于校准的 Ideal SVD。
- CSI prediction 评估明确覆盖 SGCS/NMSE、UPT、CSI reporting overhead、BLER/SE/throughput 和 FLOPs/M；AI 预测还需报告模型参数数量，并报告采样比例、采样模式及相关假设。
- AI-based CSI compression 将 CSI feedback overhead 定义为 UL resource elements 数量，要求报告 UE/NW 复杂度、模型参数及相关附加开销，并以 Rel-20 NR SSCC、NR eType II 和/或 NR Type I feedback 为基准。
- single layer deployment 的 multi-TRP 评估假设各 TRP 使用相同 antenna configuration 和 Tx power；Scenario 2 以每个 cooperative set 包含 3 个 TRPs 为基线。
- SRS 研究用途至少包括 UL transmission 和 DL transmission 的 CSI acquisition，以及 beam management；UL-based CSI acquisition 已采纳相应基本评估假设。
- tracking RS 已采纳仿真假设；finer time/frequency tracking 的设计评估至少考虑 tracking performance、overhead、NW/UE energy efficiency、UE-side complexity 和 QCL parameter(s) estimation accuracy。

**待决问题**

- TCI/QCL 的定义、QCL property/chain，以及 single-TRP、multi-TRP 和跨 cell/carrier 的 beam measurement、prediction、report 与 indication 机制仍需研究，涵盖 AI/ML 与 non-AI/ML 方法。
- UE-initiated/event-driven beam management（UEIBM）的事件定义、目标用例、触发后的 UL transmission、UE 行为及网络响应的必要性和设计尚待确定。
- PDSCH 最大正交 DMRS 端口数仍在最多 24、32、48、64 或 96 个选项间研究；叠加 Non-orthogonal DMRS 以达到网络侧目标 MIMO 层数的方案需提供链路级和系统级仿真结果。
- SRS 对更大带宽、容量与覆盖增强、动态/灵活参数适配、mTRP 和高移动场景的支持，以及 interference mitigation 和 energy efficiency 机制仍需研究。
- TDD 中联合 DL 和 UL based CSI acquisition 的具体操作仍待讨论；评估复用已同意的 DL CSI/UL CSI LLS 和 SLS methodology。
- connected 和 idle modes 下 finer time/frequency tracking RS 的带宽、频时域密度及时间行为仍需研究，Spatial domain factors 的细节仍为 FFS。

### 6GR 非地面网络（基于 9 条已摘要 6G 事件）

RAN1#124 明确了 6GR NTN 的研究原则、GNSS operation 支持目标，以及链路预算和评估参数的工作基线。上行时频同步以 NR NTN 为基线，至少在 GNSS-based operation 下支持 UE 利用自身位置与 satellite assistance information 进行预补偿，并明确支持适应卫星 RTT 的 large scheduling offsets。上述进展确立了后续物理层设计与评估方向，但具体调度实现、部分评估配置及位置使用条件仍待讨论。

**关键结论**

- NTN 研究优先识别 NTN specific issues/requirements；可采用 common/extended design，也可在其无法满足 NTN requirements 时引入 NTN specific solutions；采用 common design 时优先考虑 TN performance。
- NTN link budget template 以 TN link budget template 为基线；RAN1 将为指定轨道与频段组合定义 evaluation parameters，相关组合仅用于评估。
- 6GR NTN 目标支持 GNSS-based、GNSS-degraded 和 GNSS-less/GNSS-free operation，并采用相应术语区分至少用于物理层操作的位置可用性及 GNSS 依赖情况。
- Uplink time-frequency synchronization 以 NR NTN 为基线并遵循相同原则，引入 uplink synchronization reference point 和 satellite assistance information；至少在 GNSS-based operation 下支持 UE 时频预补偿。
- 6GR 支持 large scheduling offsets，以适应 satellite channel 引入的 RTT。
- GNSS-based operation 下的研究范围至少包括上行时频同步、HARQ、large RTT timing relationships、coverage target、multi-satellite operation、多 beam，以及 beam footprints 多于同时激活 beams 的情况。

**待决问题**

- Link budget template 的具体行、数值及新增行仍待讨论；面向 RAN1#124b 的 template 和 evaluation assumptions 输入鼓励采用 R1-2601471 所附 xls 格式。
- 各轨道与频段组合的 evaluation parameters 尚待定义；Ka band 的 LEO 300 和 LEO 1200 仍以方括号标注。
- 位置 fix 所需频率，以及是否可采用精度相当的非 GNSS 定位方式，仍待确定。
- Large scheduling offsets 的实现仍需在以 NR k_offset 为基线并可能修改，以及将较大 RTT scheduling delays 纳入类似 K1/K2 的 scheduling offsets 两种选项间进一步讨论；后者是否 TN/NTN 通用也未确定。

### 6GR 波形与帧结构（基于 12 条已摘要 6G 事件）

RAN1#124 明确将 DFT-s-OFDM 的 low UL PAPR enhancement 和多 rank UL MIMO 研究列为 AI 10.2.1 的高优先级，并将 6GR Downlink DFT-s-OFDM waveform 及相关增强移出该议题讨论范围。本会议进一步统一了 UL waveform 研究的基线、评估指标、功率模式和 precoder 假设，并扩展提案特征表以记录潜在规范影响及收发处理要求。这些进展细化了后续方案比较的共同条件，尚未形成最终 waveform 方案选择。

**关键结论**

- 通过 DFT-s-OFDM low UL PAPR enhancement 改善 UL coverage，以及 DFT-s-OFDM 多 rank UL MIMO，均按高优先级研究。
- 6GR Downlink DFT-s-OFDM waveform 及相关增强不再属于 AI 10.2.1 讨论内容；DL signal（如 SS、WUS、sensing）仍可能在相应 AI 中单独讨论。
- UL low-PAPR 提案增益以 NR Rel-15 DFT-s-OFDM 为基线；评估时公司应披露接收端所需知识，例如 filter coefficients 和 extension scheme。
- 多层 UL 研究的 SLS 指标采用 UPT 的 90% 高百分位、均值、中位数及 5/10 百分位值；LLS 指标采用禁用 HARQ 重传的 BLER curves 和 Netgain。NR reference 假设启用 Release 16 full power mode 1。
- 2-layer/2Tx UL 研究中，rank-2 transmission 对仅支持 non-coherent precoder 的 UE，两种 waveform 均仅允许 non-coherent precoder；对支持 fully-coherent precoder 的 UE，CP-OFDM 允许所有 NR precoder options，DFT-s-OFDM 仍仅允许 non-coherent precoder。
- 扩展 waveform 提案特征表，涵盖潜在规范影响、MRSS 兼容性、复用共存、多用户复用、MIMO 兼容性及 transmitter/receiver processing operation 影响，作为潜在 RAN1 observation 的描述基础。

**待决问题**

- UL low-PAPR spectrum extension/truncation 评估中，处理前子载波数 A 保留 12 × 2ˣ3ʸ5ᶻ 和 2ˣ3ʸ5ᶻ 两个选项；A 是否需要最大值仍为 FFS，占用带宽 B 以 RB 数表示。
- Non-AI-ML-based 和 AI-ML-based DFT-s-OFDM UL low-PAPR proposals 留待进一步考虑；所列 tdoc 编号仅提供提案信息，不表示这些 tdoc 支持相应提案。

### 6GR 唤醒信号与运行机制（基于 7 条已摘要 6G 事件）

本会议明确了 6GR DL WUS 的覆盖研究目标、部分 SCS 假设及设计与评估范围，并推进其在 RRC connected state 下触发 PDCCH monitoring 的机制研究。会议还纳入了 RRC idle state 下采用 EE processing 的 RRM measurement，以及 standalone cell 和 multi-cell/carrier 场景下 UL WUS 必要性与可行性的进一步研究。这些进展界定了后续协议设计的研究条件与评估要求，尚不代表所研究的 UL WUS 场景已获 6GR 支持。

**关键结论**

- DL WUS coverage 以同频段 6G PDCCH 的相同覆盖为研究目标，至少考虑 missed detection rate、false alarm rate、RRC state differences、不同用例及 PDCCH reference configuration。
- 当同频段 sync signals 与 data channels 使用相同 SCS 时，假设 DL WUS 使用与 6GR Sync signals 相同的 SCS。
- DL WUS 设计研究需考虑时域或频域序列定义、时频资源分配、与其他信号和信道的复用与共存，以及 PAPR、BS/UE 处理复杂度、网络开销和网络及 UE 能效。
- RRC connected state 下 DL WUS 触发 PDCCH monitoring 的研究涵盖有无 C-DRX 两种情况，评估需考虑 UE 节能、UPT（如适用）、时延、QoS/时延预算满足率、网络开销与复杂度及网络能耗。
- RRC idle state 下研究基于 6GR measurement signal、采用 EE processing 的服务小区与邻区 RRM measurement，评估涵盖节能、覆盖、准确度、复杂度及与 DL-WUS monitoring 同时进行和 non-EE processing 的比较；邻区还需考虑小区识别、评估、数量限制与 inter-cell interference。

**待决问题**

- FR2-1 中 sync signals 与 data channels 使用不同 SCS 时，DL WUS 的 SCS 尚待讨论（FFS）。
- standalone cell 场景下 UL WUS 的必要性与可行性仍待研究，涵盖发送前无信号、仅有常开同步信号（可带 PBCH）但无 SIB1、以及有 PBCH 和周期性 SIB1 三种情形；需研究覆盖目标、同步获取、发射功率确定及适用 RRC states。
- UE 从 cell/carrier #1 获取 UL WUS 配置的 multi-cell/carrier 场景仍需研究 UL WUS 的必要性与可行性，涵盖 cell/carrier #2 发送前无信号、仅有常开同步信号、或有 PBCH 和周期性 SIB1 的情形；需考虑覆盖、同步、发射功率、频段与共址情况、RRC states 及 multi-TRP 适用性。
