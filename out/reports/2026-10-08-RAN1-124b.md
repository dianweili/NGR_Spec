# RAN1 #124b 增量简报

> 共 202 条事件 · [会议目录](https://www.3gpp.org/ftp/tsg_ran/WG1_RL1/TSGR1_124b/)

## 本会议特性进展（6G）

### 6GR 信道编码与调制（基于 10 条已摘要 6G 事件）

本会议细化了超出 NR 范围的 LDPC extension 的 new BG 研究假设、结构约束和候选方案，为后续下选提供基础，但尚未确定最终编码结构。调制方面明确了 6G 至少支持的 NR uniform QAM 范围，并推进 PS/GS 及 FWA 更高阶 uniform QAM 的评估条件。相关进展明确了最低调制支持范围与研究比较基础，更高阶调制及 shaping 方案的支持仍需后续评估和讨论。

**关键结论**

- LDPC extension 研究假设最大 code block size 为 8448；约 2/3 的母码率假设仅适用于 new BG 研究。
- 最大信息块为 8448 bits 时，new BG 在母码率下的 lifted parity check matrix 的 1 总数不得超过参考阈值 N；N 由 BG1 在码率 X 下确定，X 不低于 1/2。
- new BG 研究进一步采用由 A、B、C、D、E 五个子矩阵组成的 encoder parity check matrix，并研究 44 个 information columns、maximum lifting size 为 192 的 single edge BG 及可组合的结构方案。
- 6G 至少支持 NR equal probability uniform QAM constellation：CP-OFDM 数据信道 DL 为 QPSK 至 1024QAM、UL 为 QPSK 至 256QAM；DFT-s-OFDM 数据信道 UL 为 pi/2 BPSK 及 QPSK 至 256QAM。
- PS/GS 的 fading channel 评估明确了优先鼓励提交结果的 SIMO、高移动速度 open-loop MIMO、rank 4 closed-loop precoding 及其他指定 MIMO 场景。
- FWA CPE 的 DL 4K uniform QAM、UL 1K uniform QAM SLS 研究确定了 Dense Urban 与 Urban Macro 参数子集，并明确按传播条件分类及联合统计的 rank、MCS 分布，以及选用上述高阶调制时的独立 rank 分布报告要求。

**待决问题**

- new BG 的最终结构仍待下选，包括 sub-matrix B 的 B1/B2、sub-matrix E 的 identity/lower triangular matrix，以及 row splitting、转换为 22 个 information columns 和 maximum lifting size 为 384、quasi-row orthogonality 等方案；目标是在 RAN1#125 下选，其他 single edge BG 方案未被排除。
- 确定 new BG 矩阵 1 总数上限 N 所用的 BG1 参考码率 X，具体值仍待确定。
- 其他调制方案或阶数的支持、低 PAPR 增强及 waveform 相关影响仍待讨论或决定。
- FWA 更高阶 uniform QAM 研究的 EVM 和 MPR 假设需要 RAN4 输入。
- 需为 RAN plenary checkpoint 补充 GS 相对 uniform QAM 的复杂度和存储需求比较，并关联性能增益或损失进行观察。
- 需为 RAN plenary checkpoint 补充不同 PS DM 算法及参数相对 uniform QAM 的复杂度和存储需求比较，并关联性能增益或损失进行观察。

### 6GR 能效（基于 12 条已摘要 6G 事件）

本会议推进了 6GR 能效评估中的功耗与状态转换参数统一，明确了 DL/UL 带宽、UL CA、发射天线及 CAT 2.1 的多项取值，并纳入 EE processing 与 RRM measurement 功耗规则。这些结果为不同配置下的能效评估提供了共同计算依据；CA scaling 以所有 CC 已激活为前提，不涉及 carrier activation/deactivation delay。CA reception 的部分参数与适用情形仍待明确，SBFD 功耗模型的具体表达式无法从所给材料确认。

**关键结论**

- 所有其他 DL signal/channel processing 使用 PDCCH-only BW scaling table 的 column；公司需报告所采用的 S_MaxBW 选项：Option A 为 0，Option B 在 MaxBW=200% 和 400% 时分别为 0.3 和 1.0。
- UL 2CC scaling 相对 1CC：inter-band CA（2 RFs）为 1.5；intra-band CA（Single RF）在 0、23、26 dBm 时分别为 1.2、1.05、1.05。同一频段内 UL 2Tx antennas 相对 1TX 的 power scaling factor 为 1.5。
- UL BW 比例为 200%、TX power level 为 0 dBm 时，power scaling 为 1.2；评估中 10 MHz BW 的 EE processing power 为对应 5 MHz 值的 1.2 倍。
- CAT 2.1 在 reference configuration sets 1–4 中的 relative power values 与 CAT 2 相同；Set 4 的 Light sleep、Deep sleep transition times 分别为 100 milliseconds、2 seconds，relative transition energy values 分别为 210、6300。
- one RF chain CA reception 的 PDCCH-only scaling 为相同总带宽下 single CC 的 bandwidth scaling 加 X × (CC number − 1)，仅一个 CC 进行 PDCCH monitoring 时 X=0；multiple RF chains 的总体 scaling 在 one RF chain CA reception 基础上加 Y × (CC number − 1)，并假设 RF chain 数等于 CC 数。
- 纳入不含 EE processing 的 RRM measurement UE power consumption：Serving cell RRM 为 100，Serving & neighbour cell RRM 按 N、同步情况及 FR1/FR2 区分，假设 neighbour cells 已知。功耗基于 100 MHz reference configuration，并可应用 BW 和 antenna scaling rules。

**待决问题**

- one RF chain CA reception 中，每个 CC 均进行 PDCCH monitoring 时的 X=[0.2] 仍以括号值列示；除全部 CC 或仅一个 CC 监测外，其他情形仍待讨论。
- multiple RF chains CA reception 中，各类信号或信道的 Y=[0.3] 仍以括号值列示；CC BW 不同于参考配置时是否采用相同 Y 值仍待讨论。
- SBFD operation 下 BS power consumption 的公式内容缺失，具体模型表达式尚无法从所给材料确认。

### ISAC 通感一体（基于 14 条已摘要 6G 事件）

本会议明确了 Rel-20 6G ISAC 感知性能评估的 baseline 场景，并确立 RS、测量与报告、waveform 和 frame structure 的研究起点。协议相关研究将比较通信 RS 复用、增强及感知专用 RS，并研究测量报告的传递路径、触发方式和信令层级；这些约定尚不构成最终协议方案。Waveform 和 frame structure 研究以 6GR 通信设计为起点，同时保留增强及其他 waveform 的研究空间。

**关键结论**

- Sensing performance evaluation 将 UAV、human、vehicle 和 AGV 的 object detection and/or tracking 场景及载频组合列为 baseline；仍可评估其他场景或载频，且不降低其优先级。
- 不同 UE 的 antenna pattern、mobility 等属性用于评估讨论，无意研究或规定多样化 device type。
- ISAC RS 研究将比较复用通信 RS、以通信 RS 复用为起点的 enhanced RS，以及 dedicated RS for sensing，至少考虑 sensing performance、resource overhead 和对 communication 的影响；RS RE patterns 也纳入研究。
- ISAC 测量研究涵盖 TRP-side 和 UE-side measurement 的定义与级别，以及非理想因素的影响；TRP-side measurement 以 NR ISAC 已研究的 measurement Levels 为起点。
- Measurement report 研究覆盖 UE 向 aNB 或 SF、aNB 向 UE 或 SF 传递测量和/或辅助信息，以及 Periodic、semi-persistent、aperiodic、event-triggered 报告方式和 L1、L2、higher layer 信令。
- Waveform 研究以 6GR 定义的 CP-OFDM 为起点，并采用 CP-OFDM 作为 sensing waveforms 优势评估的 benchmark；frame structure 研究以 6GR communication frame structure 为起点，至少涉及 frame/sub-frame/slot/symbol structure、CP length 和 SCS。

**待决问题**

- 各 baseline 场景与载频组合适用的 sensing modes，以及各 mode 的评估参数和值仍待讨论；现有 mono-static、bi-static 示例不表示任一 mode 适用于任一场景。
- Communication assistance evaluation 的必要性、感知目标与辅助方式、metrics、performance target/KPI、channel model extension 及相对 5G NR sensing evaluation methodology 的更新，待下次会议输入。
- Enhanced RS 是否用于 communication purpose 尚未决定；RS sequence 增强如有讨论，将在议程 10.8.3 处理。
- 测量定义、级别及非理想因素影响仍待研究；measurement report 各机制的适用场景与影响也待研究，可能需要 cross-WG coordination。
- CP-OFDM 增强、其他 waveforms 及 frame structure 增强仍保留研究空间，尚未形成最终选择。
- RAN1#125 待进一步讨论 LLS 和/或 SLS 的必要性及 pros/cons/metrics，以及 theoretical waveform characteristics analysis 的 pros/cons/metrics，用于评估 ISAC waveform 和/或与 communication 的集成。

### 6GR 多天线系统（基于 126 条已摘要 6G 事件）

本会议推进了 6GR 多天线系统的波束管理、上下行 CSI acquisition 及多天线传输研究，明确了部分参考信号、端口数量和传输基线，并细化性能、开销与复杂度评估框架。协议层面已支持 codebook based PUSCH transmission，并确定部分 CSI-RS、SRS 和波束报告基础能力；具体码本、参考信号映射、预测辅助信息及多 TRP 流程仍处于研究阶段，beam management 评估假设也仅部分稳定。

**关键结论**

- 6GR PUSCH 支持的 UE antenna ports 数量为 {1, 2, 3, 4, 8}；CP-OFDM 下假设 SU-MIMO 最大层数与给定端口数相同。支持 codebook based PUSCH transmission，UL CSI 获取以 SRS 为基线。
- DL-based CSI acquisition 支持 NZP CSI-RS 作为 channel measurement RS，以 CSI-IM 为干扰测量资源基线，并至少支持周期和非周期 CSI-RS；CSI-RS pattern 定义为 CDM groups 的聚合。
- SRS 支持 {1, 2, 3, 4, 8} 个 antenna ports，以 P/AP-SRS 为支持基线；序列与 pattern 研究分别以 NR ZC/CGS sequences 和规则 comb 值 {2, 4, 8} 为起点。
- Network-initiated beam reporting 在适用时至少支持 L1-RSRP，且可由 UE 测量或预测；beam management 的 LLS 性能指标采用 BLER 和 SE。
- 空间域 CSI prediction 的 Baseline #2 采用同一 polarization 内、依据 NR port indexing 的最近已测量 ports 进行 Linear interpolation，不使用 full-dimensional measurement 辅助信息；时域预测以 Sample & Hold 为基线。
- PDSCH codeword-to-layer mapping 评估以 NR spatial first、frequency second、time third mapping 及 NR codeword-to-layer mapping 为基线；CSI codebook 性能与复杂度评估以 NR codebooks 为基准。

**待决问题**

- Beam management 的 SLS/LLS 假设尚未全部稳定，QCL 定义未形成结论；UE-initiated beam management 的触发事件、多 TRP 扩展，以及基于 DL RS 的测量与报告流程仍需研究。
- CSI-RS 最大 ports 数量仍在 128、256、512 间研究，CDM group 的位置、大小和类型、RE sharing、半持续行为及其他测量 RS 的支持尚待确定。
- CSI codebook 的低/高分辨率结构、含 CJT 的 multi-TRP 支持、CSI reporting 的层级与时序、可变 payload，以及 CJT calibration 所需 CSI report 仍待研究。
- CSI prediction 的降维测量辅助信息、AI 模型泛化与可扩展性、JSCM-based CSI compression 及 CPI 用途仍需评估；joint DL/UL CSI acquisition 的误差建模和 UE reciprocity 可行性也需进一步处理。
- SRS 的资源分层、多用途复用、hopping、repetition、稀疏 pattern、超过 272 PRBs 的 sounding、动态参数适配及 precoded SRS 仍待研究；SP-SRS 是否需要支持尚未确定。
- UL codebook 的固定、可配置和混合设计，以及 UE coherency 与天线结构影响仍待研究；MU-MIMO DMRS 指示、OCC/CDM 结构、低开销 DMRS 与 AI receiver、PDCCH transmit diversity 的具体方案尚未确定。

### 6GR 非地面网络（基于 12 条已摘要 6G 事件）

本会议明确了6GR NTN的link budget评估基线、最低双工研究范围及multi-satellite operation的物理层研究边界，并补充轨道和天线模型假设。针对大RTT下的调度，原则上支持以NR的k_offset概念为基线并至少支持广播，同时继续研究HARQ stalling缓解方案、TA report和GNSS-based UL time-frequency pre-compensation。上述进展为NTN评估与协议设计提供了基线，但部分机制及其与6GR整体调度设计的衔接仍待确定。

**关键结论**

- 6GR NTN采用R1-2603091所附的link budget template，“Candidate 2”不纳入NTN考虑；S-band的link budget计算至少增加MEO-7000轨道。
- 6GR NTN study至少考虑FD-FDD和UE侧HD-FDD两种duplex types。
- 原则上支持以NR的k_offset概念为基线并允许潜在修改，且至少支持广播k_offset，以实现较大的scheduling offsets。
- multi-satellite operation至少研究mobility及inter-satellite interference management相关物理层方面及其适用性；两方面均假设UE一次只连接一颗卫星，并预期mobility主题与RAN2协调。
- link budget template给出了reflector antenna、phased arrays及UT omni antennas的antenna virtualization mode示例，Receiver部分使用与Transmitter部分相同的mode。
- S-band（2 GHz）LEO-600和LEO-300采用的SAN antenna model允许phased antenna array或reflector antenna；phased array使用fully connected TXRU mapping。两轨道天线元素数分别为1296和400，整体天线增益分别为33.126 dB和28.02 dB，template需计入50% efficiency。

**待决问题**

- 继续研究HARQ feedback disabling、跨多个slot的PDSCH/PUSCH传输、收到前次HARQ-ACK前复用同一HARQ process及增加HARQ processes等方案的适用性；方案可组合，是否与TN协调待定。
- 针对卫星beam footprints多于同时激活beams的问题，default SSB periodicity取值、hierarchical beam structure及可实现的覆盖比例和适用性仍待研究。
- inter-satellite interference management的技术细节待定。
- 是否支持UE-specific k_offset待定；若6GR不定义K1/K2等概念，或调度设计已覆盖NTN RTT范围，k_offset相关协议可能修订。
- TA report对6GR NTN是否有益仍待研究；GNSS-based operation所需的satellite assistance info参数以NR NTN SIB19参数为起点，继续研究其对UL time-frequency pre-compensation的支持。
- S-band UE antenna model考虑对应1、2、4、8个antenna elements的Combination0至Combination3；具体采用哪些组合、TXRU总数、Alt 1/Alt 2细节及对特定device types的适用性均为FFS。

### 6GR 波形与帧结构（基于 4 条已摘要 6G 事件）

本会议明确了以 DFT-s-OFDM 的 low UL PAPR enhancement 改善 UL coverage 的优先研究范围，涵盖多种 FDSS 调制及频谱处理变体，并区分 transparent filter 与 non-transparent filter 的定义路径。会议汇总了 UL DFT-s-OFDM 和相关 waveform 提案的评估情况，但系统级收益随场景与设置而异，尚不能据此形成统一增益结论。所列公司反馈均建议考虑将相关提案纳入 6GR TR；除非 RAN#112 或之后的 RAN 会议下达任务，RAN1 waveform 议题下不计划进一步讨论这些提案。

**关键结论**

- low UL PAPR enhancement 研究优先考虑所列 FDSS cases，包括 π/2 BPSK、QPSK、16QAM，以及 spectral extension 和 spectral truncation 变体。
- 各类 FDSS 均考虑 transparent filter 或 non-transparent filter：前者由 RAN4 通过 transmitter requirement 等定义，后者由 RAN1 指定 filter coefficients。
- UL DFT-s-OFDM 评估涵盖 max-rank、接收天线数、功率受限时的 Tx power gain，以及不同 codebook 和 Dynamic waveform switching 设置；系统级增益或损失随场景和评估设置而异。
- 对所列 waveform 提案是否建议考虑纳入 6GR TR，所列公司反馈均为 YES。
- 除非 RAN#112 或之后的 RAN 会议下达任务，否则 RAN1 的 waveform 议题下不计划进一步讨论所列提案。

**待决问题**

- 公司被鼓励在后续评估报告中说明是否使用 transparent CFR。

### 6GR 唤醒信号与运行机制（基于 11 条已摘要 6G 事件）

本会议明确了 DL WUS detection 的链路级覆盖评估基线及 EE mode 的部分评估假设，并给出了 FR2-1 下有条件的 SCS 假设，为后续方案比较建立共同基础。会议细化了 DL WUS 在 RRC idle 和 RRC CONNECTED state 下的运行机制研究范围，以及 EE processing 支持 RRM measurement 的研究内容，相关协议行为尚待确定。UL WUS 方面，会议明确了部分部署情形下获取同步和确定发射功率的依据，跨载波同步及所需信息仍待研究。

**关键结论**

- FR2-1 中，若同步信号和数据信道采用相同 SCS，则假设 DL WUS 与同频段 6GR Sync signals 使用相同 SCS。
- DL WUS detection 的 EE processing 链路级覆盖评估基线参考 NR common PDCCH：aggregation level 8、4 个 PDCCH 接收天线、TR38.830 定义的 CORESET、40-bit payload（不含 CRC），以及 2 个 WUS+PDCCH 发射天线。
- DL WUS link-level EE mode 评估至少采用 700 MHz、3.5 GHz 和 7 GHz 载波频率，对应 WUS SCS 分别为 15、30 和 30 kHz；其余评估参数中仍有部分为 FFS 或由公司报告。
- DS#1b 下，若 standalone cell 在 UL WUS 前发送带 PBCH 的 always-on 6GR synchronization signals，UE 可据此获取 UL WUS 所需的 DL timing/frequency synchronization；发射功率可依据 always-on 信号及可用的功率确定信息决定。
- DS#2b 下，UE 向 cell/carrier #1 发送 UL WUS 时，可通过该载波的 always-on 6GR synchronization signals 和 PBCH 获取 DL timing/frequency synchronization，并依据可用信息确定发射功率。

**待决问题**

- OFDM-based WUS sequence 的 time domain（例如 DFT preprocessing）与 frequency domain（不使用 DFT preprocessing）定义仍需比较，包括链路性能、BS/UE 检测复杂度、接收处理、PAPR，以及 multiplexing 与 coexistence。
- 需研究 DL WUS reception 所需的 6GR sync signals；若其不足，再研究额外同步方法的必要性、适用性和影响，并完善尚未确定的 EE mode 评估参数。
- RRC connected state 下，通过 EE processing 进行 serving cell 和 neighbouring cell RRM measurement 的可行性、必要性、所用信号及规范影响仍待研究，需评估节能、覆盖、精度和复杂度等因素。
- RRC idle state 下用于唤醒 UE 接收 paging 的 DL WUS 机制仍待研究，包括 PO/PF 与 WUS monitoring occasion 的关联、唤醒后行为、指示粒度、监测安排、多波束 QCL、误检与漏检后果，以及与 paging 的载波关系。
- RRC CONNECTED state 下，有和无 C-DRX 时 DL WUS 触发 PDCCH monitoring 的机制仍待确定，包括周期性监测、time offset、PDCCH 监测时长、期间是否继续监测 WUS、停止监测方式、per cell 或 cell group 触发范围及配置数量。
- UL WUS 功率信息的提供方式及所需最小信息仍待研究；DS#2b 向 cell/carrier #2 发送时，带 PBCH 情形下通过 #2 或 #1 获取同步的可行性与适用性，以及无 PBCH 情形下的同步获取方式仍待研究。

## 6GR 信道编码与调制（10 条）

- **agreement** 10.5.4.1 — 研究 6GR 连接态下 PDCCH monitoring 的适配，至少包括时域适配及相应的 signalling mechanisms。研究应至少以 NR 中的技术为起点。
- **agreement** 10.5.4.1 — 研究是否以及如何支持大于 0 slot 的 minimum DCI-to-PDSCH scheduling offset。
- **agreement** 10.5.4.1 — RAN1 研究确定 UE 需要监测的各种 DCI sizes 的方法。
- **agreement** 10.5.4.1 — RAN1 研究针对给定 DCI 确定其承载功能的方法。示例包括一个或多个 Header/Identifier fields、RNTI 和 DCI size。
- **agreement** 10.5.4.1 — 对于 6GR，单个 PDCCH 承载完整 DCI information 是基线方案，至少适用于发送给空闲态 UE 的 DCI。
- **agreement** 10.5.4.1 — 研究 6GR two-stage DCI，至少考虑适用场景、两阶段功能与信息、物理信道/信号、时序、监测与盲解码、复杂度、覆盖、可靠性、阻塞概率、资源效率、功耗、解码时延、调度时延及用户体验。还将与 single-stage DCI 比较优缺点，并鼓励公司说明研究所用的假设或设计。
- **agreement** 10.5.4.3 — 研究 6GR 是否以及如何支持小于 TB-level 的 downlink HARQ-ACK feedback granularity。评估因素包括反馈开销、重传效率和实现可行性。
- **agreement** 10.5.4.3 — 研究 6GR 是否支持跨多个 TB 的 HARQ-ACK bundling。
- **agreement** 10.5.4.3 — 研究 6GR 下行 HARQ 的 HARQ-ACK codebook 及其操作，涵盖 codebook 生成、反馈粒度、开销、DCI missing 导致的负载大小或比特顺序不匹配，以及 DTX 与 PDSCH 解码失败的歧义。还考虑调度器协调和反馈复杂度。
- **agreement** 10.5.4.3 — 6GR 下行 HARQ-ACK payload size 最小值为 1；若支持 Mechanism 1，至少可复用 5G NR Polar coding 支持的 1706 bits 上限。该上限不代表最大 HARQ-ACK payload size，确切最大值可在后续需要时确定。
- **agreement** 10.5.4.3 — 研究确定 downlink HARQ-ACK feedback 时序和资源的四种方法及其优缺点：DCI 动态指示、UE 发起反馈、使用满足 UE 处理时间/能力的半静态配置资源中下一个可用时隙，以及仅通过 RRC 配置。允许组合这些方法或采用其他方法。
- **agreement** 10.5.4.3 — 针对 6GR UL，研究对给定 HARQ process failure 采用显式或隐式指示，以触发更快的 UL ARQ procedure。
- **agreement** 10.5.5 — 以 NR 1-bit SR mechanism 为基准，研究多于 1 bit 的 SR 传输机制，以及 1-bit SR 的资源分配和 L1 触发增强。还研究 BS UL pre-scheduling、contention-based BSR transmission 和 preconfigured PUSCH（contention free）中 BSR transmission 的 L1 层面。
- **agreement** 10.5.5 — 研究 6GR UE-to-UE CLI handling，覆盖 dynamic TDD、semi-static SBFD 及其共存场景，以及多种频域和小区内外 CLI。研究 CLI 测量与报告机制（包括参考信号/信道、时序错位、测量指标、报告内容及触发方式），并研究时频资源协调、上行功控、空间域抑制和 BS 间信息交换等缓解机制。
- **agreement** 10.5.5 — 研究 6GR BS-to-BS CLI handling，覆盖 dynamic TDD、semi-static SBFD 及其共存场景，以及不同频域和小区间干扰。研究上行资源静默、测量机制/资源、协调调度、BS 间信息交换、基于 DL power allocation 的机制和空间域方案，并包括评估各项机制的必要性；其是否影响 RAN1 规范尚未确定。
- **agreement** 10.5.5 — 研究 6GR 的 remote interference management (RIM) 机制，考虑相同或不同 TDD 配置、至少一个 BS 配置为 SBFD，以及 NR BS 与 6GR BS 间的远程干扰；研究也考虑约 7GHz 的 upper mid-band。研究 6GR RIM 的 workflow、framework 和 reference signal design，以 NR 的 wireless-based 和 backhaul-based RIM framework 及 NR RIM RS 为研究起点，并以尽量减少不必要复杂度为目标。

## 6GR 非地面网络（12 条）

- **agreement** 10.7.1 — 针对NTN中大RTT导致的HARQ stalling，研究HARQ feedback disabling、跨多个slot的PDSCH/PUSCH传输、aNB在收到前次HARQ-ACK前复用同一HARQ process，以及增加HARQ processes等方案及其适用性。上述方案可组合，是否与TN协调仍待确定。
- **agreement** 10.7.1 — 6GR NTN采用R1-2603091所附的link budget template；“Candidate 2”不纳入NTN考虑。
- **agreement** 10.7.1 — 针对NTN卫星beam footprints多于同时激活beams的问题，研究default SSB periodicity的取值及hierarchical beam structure（例如采用不同尺寸的beams），并评估可实现的卫星覆盖比例和适用性。
- **agreement** 10.7.1 — 6GR NTN study至少考虑FD-FDD和UE侧HD-FDD两种duplex types。主会另列出Semi-static TDD、gNB semi-static SBFD和Dynamic TDD等6GR duplexing study类型。
- **agreement** 10.7.1 — 6GR NTN的“physical layer aspects of multi-satellite operation”至少研究与mobility及inter-satellite interference management相关的物理层方面及其适用性，干扰管理技术细节待定。上述两方面假设UE一次只连接一颗卫星，并预期mobility主题与RAN2协调。
- **agreement** 10.7.1 — 6GR NTN评估中，S-band至少为link budget计算增加MEO-7000轨道。
- **agreement** 10.7.1 — 为实现较大的scheduling offsets，6GR NTN原则上支持以NR的k_offset概念为基线并允许潜在修改，且至少支持广播k_offset。是否支持UE-specific k_offset仍待确定；若6GR不定义K1/K2等概念或其调度设计已覆盖NTN RTT范围，该协议可能修订。
- **agreement** 10.7.1 — RAN1将研究TA report对6GR NTN是否有益。
- **agreement** 10.7.1 — 针对 6GR NTN 的 GNSS-based operation，研究 UL time-frequency pre-compensation 所需的 satellite assistance info 参数，并以 NR NTN 的 SIB19 参数为起点。
- **conclusion** 10.7.1 — 6GR NTN link budget template 针对 reflector antenna、phased arrays 和 UT omni antennas 给出了 antenna virtualization mode 的示例设置，涵盖 antenna gain element、scanning loss、loss to beam edge 及元素数与模拟数的关系。上述设置适用于 template 的 Transmitter 部分，Receiver 部分使用相同的 antenna virtualization mode。
- **working_assumption** 10.7.1 — 针对 S-band（2 GHz）LEO-600 和 LEO-300，采用 SAN antenna model 假设：phased antenna array 使用 fully connected TXRU mapping，卫星天线配置可为 phased antenna array 或 reflector antenna。两种轨道的天线元素数分别为 1296 和 400，整体天线增益分别为 33.126 dB 和 28.02 dB；link budget template 中需计入 50% efficiency。
- **working_assumption** 10.7.1 — 针对 6GR NTN 的 S-band UE antenna model（all orbits），考虑 Combination0 至 Combination3，分别对应 1、2、4、8 个 antenna elements，并列出各组合的 TXRU 数量及 Alt 1/Alt 2 天线模型候选。具体考虑哪些组合、TXRU 总数、Alt 1/Alt 2 细节及组合是否适用于特定 device types 均为 FFS。

## 6GR 唤醒信号与运行机制（11 条）

- **agreement** 10.6.1.1 — 对 OFDM-based WUS sequence，进一步研究 time domain（例如 DFT preprocessing）与 frequency domain（不使用 DFT preprocessing）定义。研究方面包括 link-level performance、BS 和 UE 检测复杂度、接收处理、PAPR，以及与其他信号和信道的 multiplexing 与 coexistence。
- **agreement** 10.6.1.1 — 在 FR2-1 中，若同步信号和数据信道使用相同 SCS，则假设 DL WUS 与同频段 6GR Sync signals 使用相同 SCS。
- **agreement** 10.6.1.1 — 确定用于评估 DL WUS detection 的 EE processing link-level coverage baseline reference configuration：参考 NR common PDCCH，采用 aggregation level 8、4 个 PDCCH 接收天线、TR38.830 中定义的 CORESET、40-bit（不含 CRC）PDCCH payload，以及 2 个 WUS+PDCCH 发射天线。
- **agreement** 10.6.1.1 — 至少研究用于 DL WUS reception 的 UE sync 所需的 6GR sync signals。进一步研究额外同步方法的必要性、适用性和影响，例如额外同步信号或具有同步功能的 DL WUS，条件是 6GR sync signals 被认为不足。
- **agreement** 10.6.1.1 — 规定 DL WUS link-level EE mode 评估至少采用的假设，包括 700 MHz、3.5 GHz 和 7 GHz 载波频率，以及对应的 WUS SCS 为 15、30 和 30 kHz；还列出信道模型、UE 速度、MDR/FAR、带宽、误差建模、信息比特数和接收天线数等评估参数。部分参数仍为 FFS 或由公司报告。
- **agreement** 10.6.1.2 — 针对 RRC connected state，研究通过 EE processing 进行 serving cell RRM measurement 的可行性和必要性。考虑 UE 节能收益、覆盖与精度、测量指标、对 EE processing 复杂度的影响，并研究基于 6GR sync signal 或其他信号的测量及是否影响规范。
- **agreement** 10.6.1.2 — 针对 RRC connected state，研究通过 EE processing 进行 neighbouring cell RRM measurement 的可行性和必要性。考虑测量类型与小区识别、测量和评估、邻区数量限制、干扰、覆盖与精度、功耗和复杂度，并研究基于 6GR sync signal 或其他信号的测量及是否影响规范。
- **agreement** 10.6.1.2 — 研究基于 6GR OFDM sequence 的 DL WUS，用于在 RRC idle state 至少唤醒 UE 以接收 paging。研究范围包括节能、时延、网络开销与复杂度、PO/PF 配置及其与 WUS monitoring occasion 的关联、唤醒后的 UE 行为、指示粒度与信息比特数、监测周期和时机、多波束 QCL、误检与漏检后果，以及 DL WUS 与 paging 是否使用相同载波等事项。
- **agreement** 10.6.1.2 — RAN1 对 RRC CONNECTED state 下 DL WUS 触发 PDCCH monitoring（包括有和无 C-DRX）的研究，需涵盖周期性监测、检测后经 time offset 开始监测 PDCCH 的时长，以及 WUS 在该时段内是否继续监测。还需研究停止 PDCCH 与 WUS 监测的方式、触发范围（per cell 或 cell group）、DL WUS 配置数量及其他细节。
- **agreement** 10.6.2 — DS#1b下，若standalone cell在UL WUS前发送带PBCH的always-on 6GR synchronization signals，UE可据此获取UL WUS传输所需的DL timing/frequency synchronization。两种情形下，UE可依据always-on信号及可用的功率确定信息决定UL WUS transmission power；功率信息的提供方式及UL WUS所需最小信息仍需进一步研究。
- **agreement** 10.6.2 — DS#2b下，UE向cell/carrier #1发送UL WUS时，可通过该载波的always-on 6GR synchronization signals和PBCH获取DL timing/frequency synchronization，并依据可用信息确定传输功率。向cell/carrier #2发送时，带PBCH情形下可研究通过#2或#1获取同步的可行性与适用性；无PBCH情形下，同步获取方式仍需进一步研究。
